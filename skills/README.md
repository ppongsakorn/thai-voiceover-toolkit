# Skills

skill สำหรับ AI agent หนึ่งโฟลเดอร์ต่อหนึ่ง skill แต่ละโฟลเดอร์มี `SKILL.md` และ `scripts/` ถ้ามีโค้ดประกอบ

## skill ที่มีแล้ว

| skill | ทำอะไร |
|---|---|
| [`voxcpm2-voiceover/`](voxcpm2-voiceover/) | พากย์เสียงด้วย VoxCPM2 ในเครื่อง: เลือกโหมด (Hi-Fi clone, clone + คำสั่งอารมณ์, voice design), สร้างหลาย take, ตรวจด้วย Whisper, ตัดเสียงเงียบ ปรับจังหวะ และต่อไฟล์ |

วิธีติดตั้งให้ Claude Code ใช้: คัดลอกหรือ symlink โฟลเดอร์ skill ไปไว้ที่ `~/.claude/skills/` (ใช้ทุกโปรเจกต์) หรือ `.claude/skills/` ของโปรเจกต์ที่จะใช้

แนวทาง: ทำ skill ให้เล็กและทำงานเดียว เพื่อให้หยิบไปใช้แยกกันได้

## skill ที่วางแผนไว้

ตามขั้นตอนพากย์คลิปใน README หลัก:

- เตรียมสคริปต์ไทยก่อนสังเคราะห์เสียง (แปลงตัวเลข คำทับศัพท์ แบ่ง scene)
- สร้างเสียงราย scene และเลือก take
- ตรวจคุณภาพและปรับความยาวให้พอดีกับ scene
