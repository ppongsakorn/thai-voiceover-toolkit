# กับดักที่เจอมาแล้ว

รายละเอียดของกับดักแบบบรรทัดเดียวใน `SKILL.md` เรียงตามลำดับที่มักเจอในงาน

## 1. คำสั่งอารมณ์ไม่มีผลในโหมด Hi-Fi

เมื่อส่ง reference พร้อม transcript (`prompt_wav_path` + `prompt_text`) VoxCPM2 จะพูดต่อจาก reference และไม่สนใจ `(คำสั่ง)` หน้าข้อความ ถ้าต้องการอารมณ์ ให้ใช้ `--no-transcript` ซึ่ง `synth.py` จะส่งแค่ `reference_wav_path` แล้วคำสั่งจึงมีผล

`synth.py` ไม่ยอมรับ `--style` ในโหมด Hi-Fi และจะตัดคำสั่งในวงเล็บต้นบรรทัดออกพร้อมแจ้งเลขบรรทัด

## 2. transcript ของ reference ต้องตรงทุกคำ

ในโหมด Hi-Fi โมเดลใช้ transcript จับคู่กับเสียงใน reference ถ้ามีคำเกิน คำขาด หรือเขียนตัวเลขต่างจากที่พูด เสียงที่ได้จะเพี้ยนหรือพูดคำแปลก ๆ ต่อท้าย ให้พิมพ์ตามที่ได้ยินจริง รวมถึงคำซ้ำและคำลงท้าย

## 3. CER สูงทั้งที่อาจอ่านถูก

Whisper ถอดเสียงตามแบบของมันเอง จึงมีหลายกรณีที่ CER สูงแต่เสียงอ่านถูก ต้องฟังเองเสมอเมื่อ `check_takes.py` ขึ้น `← listen closely`

| กรณี | ตัวอย่างจากงานจริง | CER |
|---|---|---|
| คำอ่านตัวเลข | สคริปต์ `สองร้อยเก้าสิบเก้า` แต่ Whisper เขียน `299` | 0.41 |
| ตัวสะกดที่ใช้ได้ทั้งสองแบบ | สคริปต์ `ลิงก์` แต่ Whisper เขียน `ลิงค์` | 0.02 |
| ชื่ออังกฤษที่สะกดเป็นไทย | สคริปต์ `โคไพล็อต` แต่ Whisper เขียน `Copilot` | สูง |
| อคติของ Whisper | ได้ยิน "Claude Code" เป็น "Cloud Code" ทั้งที่ TTS อ่านถูก | สูง |
| คำสั้นที่ Whisper ไม่ได้ยิน | `พิมพ์ แอท ตามด้วยชื่อ` ถอดได้ `พิมพ์ ตามด้วยชื่อ` (ยังไม่ได้ฟังว่าโมเดลพูดคำนี้หรือไม่) | 0.07 |

`check_takes.py` จะเตือนเพิ่มเมื่อ Whisper เขียนเป็นตัวเลขแต่สคริปต์ไม่มีตัวเลข ส่วน CER ที่ต่ำก็ไม่ได้แปลว่าวรรณยุกต์ถูก

## 4. ชื่ออังกฤษบางคำอ่านผิด

| คำ | ผล | ใช้ในสคริปต์ |
|---|---|---|
| GPT, Gemini, Codex, AI | อ่านถูกจากตัวสะกดอังกฤษ | สะกดอังกฤษ |
| Copilot | อ่านผิด | `โคไพล็อต` |
| Claude Code | ใช้ตัวสะกดไทยตั้งแต่แรก | `คล้อดโค้ด` |
| `@` | สัญลักษณ์ไม่ถูกอ่าน | `แอท` |

ให้ลองตัวสะกดอังกฤษก่อน แล้วค่อยเปลี่ยนเป็นตัวสะกดไทยเฉพาะคำที่อ่านผิด เก็บข้อความที่ขึ้นจอ (ซับ) แยกจากข้อความที่ส่งให้โมเดล

## 5. ตั้ง `HF_HUB_OFFLINE=1` ก่อนโหลด weights แล้วจะ error

การรันครั้งแรกต้องต่อเน็ตเพื่อโหลด weights ของ VoxCPM2 ราว 5 GB และของ Whisper ราว 3 GB ทั้งสองเป็น public จึงไม่ต้องมี token หรือบัญชี Hugging Face เมื่อ `doctor.py` แสดงว่า weights ทั้งสองอยู่ใน cache แล้ว จึงค่อยตั้ง `HF_HUB_OFFLINE=1`

## 6. ตั้งชื่อ reference ให้บอกว่าเป็นเสียงสังเคราะห์

เคยมีไฟล์ชื่อ `..._human_ref.wav` ที่จริงเป็นเสียงจาก TTS อีกตัว ทำให้เข้าใจผิดภายหลังว่าเป็นเสียงคน ถ้า reference มาจาก voice design หรือ TTS อื่น ให้ใส่คำว่า `design` หรือชื่อเครื่องมือไว้ในชื่อไฟล์ เช่น `design-narrator-warm.wav`

## 7. คำสั่งอาจถูกอ่านออกเสียง

ถ้า take ขึ้นต้นด้วยคำที่ไม่มีในสคริปต์ แปลว่าโมเดลอ่านคำสั่งในวงเล็บออกเสียง ให้ตัดคำสั่งให้สั้นลงและเอาเครื่องหมายแปลก ๆ ออก ในการทดลองคำสั่ง 7 แบบใน `pacing-and-emotions.md` ยังไม่พบกรณีนี้

## 8. อย่ารันหลาย process พร้อมกัน

แต่ละ process ของ `synth.py` โหลดโมเดลแยกกันและใช้หน่วยความจำราว 14 GB ให้รวมทุกบรรทัดไว้ในการรันครั้งเดียว และใช้ `--only` เมื่อจะแก้บางบรรทัด

## 9. ไม่มี GPU จะช้ามาก

ถ้า `doctor.py` แสดง device เป็น `cpu` โมเดลยังรันได้แต่ช้ากว่าหลายเท่า บน Mac ต้องเป็น Apple Silicon จึงจะใช้ MPS ได้

## 10. ห้ามเปิด `normalize=True` กับข้อความไทย

ตัวแปลงข้อความในตัวของ voxcpm 2.0.3 รองรับแค่ภาษาจีนกับอังกฤษ ข้อความที่ไม่มีอักษรจีนจะถูกส่งไปตัวแปลงภาษาอังกฤษ ทดสอบแล้ว `ราคาเริ่มต้นที่ 299 บาท` กลายเป็น `ราคาเริ่มต้นที่ two hundred and ninety nine บาท` และ `14/11/2026 เวลา 10:30` กลายเป็น `the fourteenth of november twenty twenty six เวลา ten thirty` สคริปต์ของ skill นี้ปิดตัวแปลงนี้ไว้ ให้เขียนคำอ่านไทยเองในสคริปต์

ลำดับการแก้คำที่อ่านผิดทั้งหมด ตั้งแต่สุ่มใหม่ไปจนถึง retrain อยู่ใน `knowledge/fixing-mispronunciation.md` ของ repo นี้
