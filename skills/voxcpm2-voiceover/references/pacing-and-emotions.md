# จังหวะการพูดและคำสั่งอารมณ์

## จังหวะ

VoxCPM2 ไม่มีพารามิเตอร์ความเร็ว จังหวะคุมได้สามทาง

1. **จังหวะของ reference** ในโหมด Hi-Fi โมเดลพูดตามจังหวะของ reference ถ้าต้องการเสียงช้า ต้องอัด reference ที่พูดช้า
2. **ช่วงเงียบระหว่างประโยค** ใช้ `finish.py --join --gap-ms`
3. **`atempo` หลังสร้างเสียง** ใช้ `finish.py --tempo` ซึ่งเปลี่ยนความเร็วโดยไม่เปลี่ยนระดับเสียง และวรรณยุกต์ไม่เพี้ยน ไม่ควรตั้งต่ำกว่า 0.85

| งาน | ค่าที่ใช้ | ผลที่ได้ |
|---|---|---|
| เล่านิทาน (ผ่านการอนุมัติแล้ว) | reference ที่พูดช้า, สร้างทีละประโยค, `--gap-ms 750`, `--tempo 0.90` | ราว 8 ตัวอักษรไทยต่อวินาที |
| หนังสือภาพที่ต้องช้ากว่า | `--gap-ms 1200`, `--tempo 0.85` | ช้ากว่าแบบเล่านิทาน |
| คลิปสั้นที่ต้องวางเสียงตาม scene | หนึ่งไฟล์ต่อ scene, `--tempo 1.0` | ดู `syncing-to-video.md` |

ข้อสังเกตจากการทดสอบ:

- เมื่อใช้ `--join` ค่า tempo มีผลกับช่วงเงียบด้วย เช่น `--gap-ms 750 --tempo 0.90` จะได้ช่วงเงียบจริงราว 830 ms
- ใช้ reference เดียวกัน โหมด clone ที่ไม่มี transcript พูดเร็วกว่าโหมด Hi-Fi คือราว 10–15 ตัวอักษรต่อวินาที เทียบกับ 9–10 ตัวอักษรต่อวินาที (ทดสอบกับประโยคสั้น 5 ประโยค)
- คำสั่งอารมณ์ทำให้จังหวะเปลี่ยนมาก ประโยคเดียวกันยาว 66 ตัวอักษร ใช้เวลาตั้งแต่ 4.0 ถึง 8.0 วินาทีแล้วแต่คำสั่ง ถ้าประโยคที่มีคำสั่งเร็วหรือช้าไปทั้งชุด ให้แก้ถ้อยคำของคำสั่งก่อน แล้วจึงค่อยปรับ `--tempo`
- VoxCPM2 กำหนดความยาวเสียงเป็นวินาทีไม่ได้ ถ้าต้องให้พอดีกับ scene ให้แก้สคริปต์ก่อน แล้วใช้ `--tempo` เป็นทางสุดท้าย

## คำสั่งอารมณ์

ส่งได้สองแบบ คือ `--style "..."` สำหรับทุกบรรทัด หรือใส่ `(...)` ไว้ต้นบรรทัดในสคริปต์ ถ้าใช้ทั้งสองแบบ `synth.py` จะรวมเป็นคำสั่งเดียวโดยใส่ `--style` ไว้ก่อน ทั้งสองแบบใช้ได้เฉพาะโหมด clone (`--no-transcript`) และ design

ถ้อยคำด้านล่างมาจากการทดลองเมื่อ 11 ต.ค. 2026 กับประโยคภาษาไทย ใช้ cfg 2.0 และ 10 steps ผลคือทุก clip พูดครบประโยคและไม่มี clip ใดอ่านคำสั่งออกเสียง **แต่ยังไม่มีใครฟังตัดสินว่าแต่ละอารมณ์ฟังถูกต้องหรือไม่**

| อารมณ์ | ถ้อยคำ |
|---|---|
| อบอุ่น (ค่าตั้งต้นของงานเล่านิทาน) | `warm, gentle bedtime storytelling tone, slow` |
| ร่าเริง | `cheerful, bright and happy tone` |
| ตื่นเต้น | `very excited, energetic, slightly faster` |
| กระซิบ | `whispering softly, secretive` |
| เศร้า | `sad, slow, low voice` |
| ลุ้นระทึก | `tense, suspenseful, slow and quiet` |
| ประหลาดใจ | `surprised, amazed` |

กติกาในการเขียนคำสั่ง:

- เขียนเป็นภาษาอังกฤษ เพราะเอกสารของ VoxCPM2 รองรับคำสั่งภาษาอังกฤษและจีน ควรสั้นไม่เกิน 120 ตัวอักษร และไม่ต้องใส่วงเล็บเองเมื่อส่งผ่าน `--style`
- บอกว่า "พูดอย่างไร" ไม่ใช่ "ใครพูด" ถ้าเขียนว่า `a young girl...` เสียงจะเปลี่ยนเป็นคนอื่น
- อย่าใส่คำบอกความเร็วไว้ในคำสั่งอารมณ์ถ้าจะใช้คู่กับคำบอกความเร็วอีกตัว เช่น `warm` ที่มีคำว่า slow อยู่แล้ว เมื่อใช้คู่กับ `a little faster` จะกลายเป็นคำสั่งที่ขัดกันเอง
- ตัวขยายจังหวะ (`slower`, `a little faster`) และระดับ (`subtle`, `strongly`) ยังไม่ได้ทดสอบ
- อารมณ์ที่ได้ต่างกันไปในแต่ละ take ควรฟังหลาย take ก่อนตัดสิน
- reference ที่พูดเสียงเรียบเมื่อนำไปพูดประโยคอารมณ์จัดมักจะเพี้ยน ถ้างานต้องใช้หลายอารมณ์ ควรอัด reference แยกตามอารมณ์
