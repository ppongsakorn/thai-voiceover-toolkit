## ข้อแก้ไขที่ควรรู้

- รายงานฉบับเต็ม (รอบแรก) เขียนว่า IndexTTS ต้องติดต่อ bilibili เพื่อใช้เชิงพาณิชย์ การค้นคว้ารอบสองพบว่า licence ผ่อนกว่านั้น: ใช้ได้โดยไม่เสียค่าใช้จ่ายจนกว่าจะเกิน 100 ล้านผู้ใช้ต่อเดือนหรือรายได้ 1 พันล้านหยวนต่อปี รายละเอียดอยู่ใน `notes/2026-11-14-indextts-thai.md` หน้าสรุป HTML แก้แล้ว
- รายงานฉบับเต็มไม่มีเรื่องอัปเดตของ VoxCPM2 และโมเดลที่ออกช่วง ต.ค. ถึง พ.ย. 2026 (ZONOS3-Mini, Audio8-TTS-Realistic, Ming-3.0 TTS) เรื่องเหล่านี้อยู่ในหน้าสรุป HTML เท่านั้น
