# thai-voiceover-toolkit

Skills, tools, and research for AI voiceover and voice cloning, with a focus on Thai. Script prep, TTS generation, quality checks, and model comparisons.

รวม skill เครื่องมือ และงานค้นคว้า สำหรับงานพากย์เสียงและโคลนเสียงด้วย AI เน้นภาษาไทยเป็นหลัก และรองรับภาษาอังกฤษ

> สถานะ: เพิ่งเริ่มต้น ตอนนี้มีเฉพาะงานค้นคว้าและเกณฑ์ทดสอบ ส่วน skill และ tools ยังไม่มีโค้ด

## โครงสร้าง

| โฟลเดอร์ | เก็บอะไร | สถานะ |
|---|---|---|
| [`research/`](research/) | รายงานและบันทึกการค้นคว้าเรื่อง TTS และ voice cloning | มีรายงานชุดแรก (14 พ.ย. 2026) |
| [`eval/`](eval/) | เกณฑ์คุณภาพเสียงและแผนฟังเทียบ | มีเกณฑ์ ยังไม่มีผลทดสอบ |

| [`examples/`](examples/) | สคริปต์ตัวอย่างพร้อมผลลัพธ์ | ยังว่าง |

## ขั้นตอนพากย์คลิปที่ repo นี้ยึดเป็นหลัก

1. **เตรียมสคริปต์** แปลงตัวเลขเป็นคำไทย และคำอังกฤษเป็นคำอ่าน แล้วแบ่งเป็นราย scene
2. **สร้างเสียงทีละ scene** หนึ่งไฟล์ต่อ scene ใส่ tag อารมณ์เป็นภาษาอังกฤษ
3. **สร้างหลาย take แล้วเลือก**
4. **ฟังตรวจด้วยหู** โดยเฉพาะวรรณยุกต์ ตัวเลข คำทับศัพท์ และการหยุดกลางคำ
5. **ปรับความยาวให้พอดี** แก้สคริปต์ก่อน แล้วค่อย generate ใหม่ ใช้ ffmpeg `atempo` เป็นทางสุดท้าย
6. **รวมเสียงกับภาพ**

ที่มาและเหตุผลของแต่ละขั้นอยู่ในรายงานใน [`research/`](research/)
